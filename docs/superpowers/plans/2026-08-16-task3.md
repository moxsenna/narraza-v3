### STEP 2: Prisma Model Updates

#### CreditReservation Model

Added fields:
```prisma
quoteId         String?   @map("quote_id")
confirmationRequestId String? @map("confirmation_request_id")
billingAllocations CreditBillingAllocation[]

@@unique([quoteId])
@@unique([confirmationRequestId])
```

**Rationale:** Quote confirmation creates canonical FK → allows quote to become unconsumable after binding; confirmation_request_id provides idempotency key for quote→reservation transition.

#### CreditQuote Model

Added:
```prisma
confirmationRequestId String? @map("confirmation_request_id")
reservation  CreditReservation? @relation(fields: [id], references: [quoteId])

@@unique([userId, requestId])
@@unique([userId, confirmationRequestId])
```

**Note:** `projectId` field added to `CreditQuote` was already present in current schema (M0/W1.1 evolution). Only new is unique constraint on confirmation_request_id at user level.

#### GenerationJobs Model

Added CHECK constraint via SQL migration (not Prisma model attribute due to Prisma 7 syntax limitations):
```sql
CHECK ("workflow_plan_id" IS NULL OR "bundle_id" IS NOT NULL)
```

**Name:** `generation_jobs_workflow_plan_requires_bundle_check`

#### CreditBillingAllocations Model (New)

```prisma
model CreditBillingAllocation {
  id                  String   @id
  reservationId       String   @map("reservation_id")
  usageAttemptId      String?  @map("usage_attempt_id")
  usableOutputKind    String   @map("usable_output_kind")
  usableOutputRef     String   @map("usable_output_ref")
  amountMicroIdr      BigInt   @map("amount_micro_idr")
  createdAt           DateTime @default(now()) @map("created_at") @db.Timestamptz(3)

  reservation         CreditReservation @relation(fields: [reservationId], references: [id], onDelete: Cascade)

  @@index([reservationId, usableOutputKind, usableOutputRef])
  @@index([usageAttemptId])
  @@map("credit_billing_allocations")
}
```

### STEP 3: Raw SQL Migration

**File:** `prisma/migrations/20260816094500_credit_engine_v1/migration.sql`

**6 Steps:**

1. **Add quote_id to credit_reservations** – FK to credit_quotes, UNIQUE constraint, cascade ON DELETE SET NULL
2. **Add confirmation_request_id** – partial unique index WHERE NOT NULL
3. **Create credit_billing_allocations** – full table definition with FK + indexes
4. **Ledger append-only trigger** – BEFORE UPDATE/DELETE raises exception
5. **BillingAllocation append-only trigger** – same pattern
6. **GenerationJobs CHECK** – enforces semantic invariant

**Trigger Functions:**
- `fn_credit_ledger_enforce_immutability()` – denies mutations
- `fn_credit_billing_allocation_enforce_immutability()` – denies mutations
