# Audit UX New-User — Narraza produksi (2026-09-14)

Metode: walkthrough langsung di https://narraza.web.id sebagai pengguna baru
(anonim → daftar → verifikasi via flag DB → login → proyek → chat → fondasi →
outline → kredit → pengaturan → karakter/fakta/tulis), desktop 1280px + mobile
375px. Akun audit (`audit-ux@narraza.web.id`) sudah di-purge dari DB produksi.

## Kesimpulan

Aplikasi **jujur dan bisa dipakai tanpa bingung besar**: empty state jelas,
aksi utama selalu terlihat, tidak ada data palsu, dan setiap batasan dikomunikasikan.
Dua temuan kritis di bawah ini harus diperbaiki sebelum promosi luas.

## P0 — kritis

| # | Temuan | Bukti | Saran |
|---|---|---|---|
| 1 | Raw message code tampil di UI: membuat Roadmap tanpa fondasi terkunci me-render `msg.outline.foundation_not_locked` | outline page, alert role | Petakan ke copy Indonesia ("Kunci fondasi dulu...") + tambahkan pola `msg.` ke `no-internal-strings` checker |
| 2 | Link email verifikasi/reset redirect ke `localhost:5400` (req.url internal di balik Tunnel) | laporan owner + kode `route.ts` | **Sudah diperbaiki di PR #25 (merged), BELUM deploy** → deploy master terbaru ke VPS segera |

## P1 — mayor

| # | Temuan | Saran |
|---|---|---|
| 3 | User baru saldo 0 tanpa penjelasan cara dapat/top-up kredit; aksi berbayar pertama akan membingungkan | Tambah penjelasan perolehan kredit di halaman kredit + onboarding singkat; grant awal (kalibrasi M7) |
| 4 | Counter sinyal chat tetap 0/6 setelah pesan substantif (ekstraksi mati di prod) — terasa mati | Sembunyikan counter sampai ekstraksi live, atau microcopy jujur ("dihitung saat Narra aktif") |

## Yang sudah bagus (pertahankan)

- Next-action selalu jelas (beranda proyek → chat; tulis → outline; readiness → rekomendasi berikutnya).
- Progressive disclosure outline (form anak disabled + alasan) dan readiness checklist berbobot + %.
- Semua state kosong jujur; tombol disabled beralasan; error auth generik anti-enumerasi.
- Navigasi mobile 5 tab + sheet Lainnya; focus ring, skip link, landmark, live region.
- Branded 404 + error dengan jalan kembali.
